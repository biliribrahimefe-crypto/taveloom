# Taveloom for Android

Flutter client. It renders the workspaces your Windows PC sends and forwards taps as authenticated action ids; it never runs
anything itself.

> **Status:** `flutter analyze` is clean, `flutter test` passes (5 tests), and `flutter build apk --release` succeeds (Flutter 3.47.9, JDK 21).
> The app has **not** been run on a device or emulator. The release APK is signed with the debug key.

## First-time setup

The Android platform folder is generated by Flutter, so it is not checked in. From this directory:

```bash
flutter create --platforms=android --org dev.efedev --project-name taveloom .
flutter pub get
```

Then add the camera permission to `android/app/src/main/AndroidManifest.xml` (inside `<manifest>`, next to `INTERNET`):

```xml
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.CAMERA"/>
```

Set `minSdkVersion` to 23 or higher in `android/app/build.gradle(.kts)` (required by `flutter_secure_storage` and `mobile_scanner`).

## Run, test, build

```bash
flutter analyze
flutter test
flutter run            # with a device or emulator attached
flutter build apk --release
```
